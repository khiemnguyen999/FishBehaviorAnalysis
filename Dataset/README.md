The example fish swimming videos used in this study were obtained from Pexels. However, the proposed framework is designed to analyze any fish swimming video. Users may use their own videos or, if unavailable, download the example video provided below for testing. Due to the large size of the video files, they are not included in this repository.

Sample videos can be downloaded from:
